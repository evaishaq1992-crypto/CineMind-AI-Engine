# CineMind - AI-Powered Movie Discovery Engine 🎬✨

CineMind is an intelligent, client-side movie recommendation web application featuring natural language search, hybrid recommendation algorithms, and mood-based discovery.

## ✨ Key Features
- 🤖 **Natural Language AI Search:** Query movies using context like *"Intense crime drama"* or *"films like Inception"*.
- 🎭 **Mood & Genre Filtering:** Explore curated picks based on emotional preferences and genres.
- ⚡ **Client-Side Hybrid ML Engine:** Lightweight TF-IDF style keyword expansion and synonym matching running directly in JS.
- 🎨 **Modern Dark UI:** Responsive dashboard design with sidebar navigation and crisp card views.

## 🚀 Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- Custom Machine Learning Engine (`hybrid`, `tokenize`, `expand`, `search`)
